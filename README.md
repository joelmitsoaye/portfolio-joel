# Portfolio de Koffi Joël Mitsoaye

Site statique (HTML, CSS, JavaScript), sans outil de build.

## Structure
- `index.html`, `style.css`, `script.js`
- `assets/img/` : photos (`joel-accueil.png`, `joel-portrait.jpg`) et `works/` (visuels de réalisations)

## Formulaire de contact
Le formulaire envoie un e-mail via FormSubmit vers joelmitsoaye@gmail.com.
Au premier envoi, FormSubmit envoie un e-mail de confirmation à cette adresse : cliquez sur le lien pour activer le formulaire.

## Publier sur GitHub Pages
1. Créez un dépôt GitHub et envoyez-y tout le contenu de ce dossier.
2. Settings > Pages > Source : branche `main`, dossier `/ (root)`.
3. Le site est disponible à l'adresse affichée (https://VOTRE-NOM.github.io/NOM-DU-DEPOT/).

## Personnaliser
- Couleurs et thème sombre : variables en haut de `style.css`.
- Réalisations : tableau `WORKS` en haut de `script.js`.
